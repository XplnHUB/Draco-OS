# draco_core

`draco_core` is the foundational library crate for the Draco-OS ecosystem.

## Functionality
This crate contains shared code, data types, and utilities that are used across multiple Draco-OS services. It ensures consistency and reduces code duplication.

## Implementation Plan
- Define common configuration structures (e.g., system settings, user preferences).
- Provide shared utility functions (e.g., specialized logging, path resolution).
- Define shared data models that might be passed between different components.
